“Masterful.” “Raw.” “Breathtaking.” Sources report that all of these are adjectives. “Superb.” That is another one. “Chilling.” “Spooky.” “Cozy.” Those three are fall themed. “Strange.” “Irreverent.” David Lynch, anyone? “Powerful.” “Inspiring.” Sounds like a tear-jerker. “Absorbing.” “Adventurous.” “Ambitious.” Those all start with the letter ‘A’. “Beautiful.” “Bitersweet.” Those start with the letter ‘B’. “Dystopian.” Tricked you!

“Tour-de-force.” THAT IS A NOUN.
